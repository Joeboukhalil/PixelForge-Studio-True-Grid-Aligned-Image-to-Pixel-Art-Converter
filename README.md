# PixelForge-Studio-True-Grid-Aligned-Image-to-Pixel-Art-Converter
A single-file browser studio that converts photos and illustrations into authentic, grid-aligned pixel art using Median Cut color quantization, retro palettes, and Bayer or Floyd–Steinberg dithering. Export true 1:1 native sprites or crisp nearest-neighbor upscaled PNGs directly from your browser with zero dependencies.
